# 需求文档

## 1. 应用概述

「村庄连连看 · 转盘抽奖」是一款以村庄元素为主题的休闲消除与抽奖小游戏。玩家通过微信一键登录或账号登录后，可参与8×8连连看关卡获取金豆与抽奖机会，在商城兑换道具或参与转盘抽奖。游戏数据与玩家资产由后端数据库持久化存储，支持跨设备同步，并配备管理后台供管理员维护全局配置与导出玩家数据。

## 2. 用户与使用场景

### 2.1 目标用户
- 普通玩家：通过微信一键登录或账号密码快速进入游戏，参与关卡消除、签到打卡、转盘抽奖及道具兑换，享有跨设备存档能力。
- 游戏管理员：登录后台统一调整下发全局游戏配置，查看全量玩家数据汇总及记录并支持导出。

### 2.2 核心使用场景
- 玩家进入游戏前通过微信一键授权完成注册/登录，同意相关协议后载入云端存档进行游戏。
- 玩家清除缓存或更换设备后，重新登录即可恢复个人游戏资产与历史记录。
- 管理员在后台修改通关奖励、转盘权重及商城价格等配置，实时生效至所有玩家端。
- 管理员在后台查看全部玩家的数据概况、签到记录和中奖记录，并导出为文件进行统计分析。

│   ├── 其他登录方式入口（账号密码/验证码登录）

### 3.2 玩家登录页
- **微信一键登录**：展示微信一键登录按钮，点击后唤起微信授权流程；新用户首次授权自动完成注册与账号绑定，老用户直接完成身份验证并登录。
- **用户协议与隐私政策**：提供《用户协议》与《隐私政策》勾选框，默认处于未勾选状态。玩家需手动勾选同意后方可继续登录流程。
- **其他登录方式**：页面底部提供「其他登录方式」切换入口，支持玩家切换至手机号验证码或账号密码方式登录/注册。
- **状态提示**：授权登录过程中展示加载中提示；授权失败或拒绝时展示明确的状态提示信息。

### 3.3 游戏主界面
- **8×8 连连看关卡**：展示村庄元素方块矩阵，支持消除匹配逻辑、道具使用与通关奖励下发。
- **转盘抽奖**：支持消耗抽奖机会进行转盘抽奖，奖项与中奖概率严格基于后端下发的全局配置执行。
- **金豆商城**：支持使用金豆兑换重排道具与抽奖机会，商品价格严格基于后端下发的全局配置展示与扣减。
- **每日签到弹窗**：
  - 进入游戏时根据后端记录判定当日签到状态，未签到时自动弹出。
  - 展示连续签到天数进度及递增奖励。
  - 玩家点击签到后，签到结果与连续天数实时同步保存至后端数据库。
- **数据持久化与同步**：玩家资产（金豆、抽奖机会、重排道具、已获奖品、广告观看次数、签到记录、连续签到天数及累计统计数据）均绑定至玩家账号并永久存储于后端数据库。

- **后台登录页**：
  - 提供账号、密码输入框及登录验证。
  - 预设管理员账号：`15729129390`，密码：`12312300`。

  - **玩家数据汇总**：查看全量玩家汇总数据（包含金豆总数、剩余抽奖机会、广告观看次数、累计统计等），查看各玩家的详细签到记录与中奖/奖品发放记录。
  - **数据导出**：支持将玩家汇总数据、签到记录及中奖记录一键导出为数据文件。
  - **全局游戏配置管理**：支持管理员在线调整通关奖励抽奖机会、转盘各奖项权重比例及商城道具兑换价格；保存后统一写入数据库并生效下发给所有玩家。

## 4. 业务规则与核心逻辑

1. **登录与协议校验规则**：玩家发起登录操作前，系统必须校验用户协议与隐私政策勾选状态；若未勾选，中断登录流程并弹出提示引导玩家勾选。
2. **微信身份绑定规则**：微信一键登录通过获取微信用户唯一标识进行鉴权；未注册用户首次登录自动生成对应玩家游戏账号并完成绑定，已注册用户直接读取对应存档进入游戏。
3. **数据持久化与一致性规则**：玩家所有的资产变动、关卡结算、签到行为、抽奖结果及广告观看数据均以数据库中对应账号记录为准，确保清空浏览器缓存或更换设备后数据不丢失。
4. **全局配置动态分发规则**：通关奖励机会数、转盘奖项权重、商城道具价格由管理员在后台统一维护并保存至数据库，游戏前端加载时拉取最新配置并应用。
5. **签到周期与递增规则**：签到以自然日为周期，连续签到天数逐日累加；若断签则连续天数重置为第1天，签到状态以服务端校验为准。
6. **后台鉴权与导出规则**：仅账号 `15729129390` 与密码 `12312300` 鉴权通过后允许访问管理页面；管理员可筛选或全量导出玩家汇总数据与中奖明细。

## 5. 异常与边界情况

| 序号 | 场景 | 处理方式 |
| :--- | :--- | :--- |
| 1 | 未勾选协议点击微信登录 | 弹窗提示「请先阅读并同意用户协议与隐私政策」，阻止唤起授权 |
| 2 | 微信授权被用户拒绝或中断 | 提示「微信登录已取消」，停留在登录页供玩家重新尝试或切换方式 |
| 3 | 配置参数输入非法格式 | 限制输入数值类型，数值不合法或权重总和异常时阻止保存并提示 |
| 4 | 后台登录账号或密码错误 | 提示账号或密码错误，拒绝登录进入管理页 |
| 5 | 玩家在多处同时更新资产 | 以服务端最新数据为准执行原子扣减与增加，防止数据透支或异常 |

4. 登录成功后进入游戏主界面，玩家的金豆、道具、抽奖次数及签到记录等资产正常展示并与数据库保持同步。
